# EpiCDRI — Epidemiologia Computacional das Doenças Respiratórias Infecciosas

Simulador educacional SEIR baseado em agentes para doenças respiratórias infecciosas.

## Arquivos

- `index.html`
- `style.css`
- `script.js`

## Como usar localmente

Abra `index.html` no navegador.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Vá em `Settings > Pages`.
4. Selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Acesse o link gerado pelo GitHub Pages.

## Acesso restrito

Senha padrão: `epicdri-admin`.

Atenção: esta área é apenas uma interface local no navegador, baseada em `localStorage`. Em GitHub Pages não há backend, logo não há autenticação real. Para controle seguro, use backend, banco de dados e autenticação.

## Observação científica

Este é um modelo didático e exploratório, não preditivo.
